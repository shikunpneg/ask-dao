从一到多：母题生长为问题树，树与树交叉处，生出新问题。

一 · 母题

领域由母题组成。母题是**能生成问题的基元**——有载体、有生成规则、有判定路由。

二 · 问题树

每个真伪问题向深处分支：计数 → 刻画 → 渐近 → 机制 → 规范。已解决的层，向下推一格就是新问题。

三 · 领域交叉

不同的树交叉时产生新问题。融合必须有**结构桥梁**——两边共享结构，否则只是空洞的笛卡尔积。

万物 · 两条路

一条生产**问题**（需解决），一条生产**概念**（需解释）。两条路独立，各有各的成功标准。

Architecture

问道系统的结构

不是问答机。它由四个模块支撑两条独立的路：一条把困惑变成可判的问题，一条把词变成可理解的概念。

问题路

PROBLEM PATH · 产问题 · 需解决

输入：外部信息 / 日常问题 / 母题
流水：日常问题 → 前问题 → 科学问题 → 基础领域 → 问题树 → 领域融合
出口：可判问题清单（带判定路由）→ AI4S 求解
标准：答案成立 / 可判

想象路

IMAGINATION PATH · 产概念 · 需解释

输入：词
流水：组词 → 拆词(深度d) → 还原造句 → 成段 → 解释
出口：被理解的概念 / 理论
标准：语法正确 + 逻辑通畅 + 有推理判断
