# PLAN_TENSION_DETECTOR —— 新方向：语料张力探测器

> 与 MASTER_PLAN(问题制造器) 并存：前者在玩具/数学空间造问题，本方向在**真实知识流的裂缝**里找"大问题候选"。
> 理论依据：科学史 15 大问题多为 张力检测(M2 异常/M6 悖论/M1 统一)，不是生成；张力存在于真实主张集合，不在一机自造空间。

## 目标
从我们几千万字语料(中西哲学史/科学哲学手册/译丛)里，批量找出"张力候选"：
- T1 概念跨体系不相容(同一概念在两套框架被以冲突方式使用)
- T2 同文/同派内 断言与其反方 并存(自洽性压力点)
- T3 两套成功框架描述同一对象(统一候选)
- T4 常识断言 vs 反例/异常并存(反常候选)

## 方法 v0(已可跑)
对每对"概念两极化关键词组"(如 知先行后 vs 行易知难)：
- 在同一文本/邻近窗口内同时命中两极 → 张力候选(该文本正在处理此裂缝)
- 输出: 文件/概念对/命中行摘要/计数
局限(诚实): 关键词启发、命中≠真矛盾, 需语义复核; v0 只筛"候选裂缝位置"。

## 语料清单(在本机 _text/)
中哲史第2版 / 西方哲学史(中文半部) / 哲学100问 / 爱思唯尔手册8卷 / 人文社科译丛 / 社会学文库…

## 管线(逐步)
1. v0 两极关键词扫描 → 候选 JSON/MD (本轮)
2. v1 邻近窗(±n句) + 发言者归属(句首人名) → 判定是否"同一人自相矛盾"还是"两派对峙"
3. v2 概念嵌入缺失下的 结构同现网络 (以类取: 用母题词典做概念谱)
4. v3 接当务评价器(big_score) → 张力→大问题候选 → 人工复核通道

## 指标/里程碑
- T0: 首批 ≥20 张力候选、且 ≥5 能被引文复核为"真张力"(非巧合共现)
- T1: 出现"两套框架冲突但都被文本视为对"的候选 → 最像 M6 悖论型大问题前身
- 与原方向汇合: 张力候选喂给 问题制造器 当"种问题"(seed)，当务分≥5 进大问题队列

## 与旧方向关系
旧方向: 生成-判定-裁判(复现+筛新)。新方向: 输入真实主张库 → 输出张力(裂缝)。两者在"当务评价→大问题队列"处汇合。
