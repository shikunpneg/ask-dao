# METHODOLOGY3 —— 自动化交叉探索管线（笛卡尔 × 四步过滤 × 数值验证 × 人类裁决）

> 用户建议的方法论三，落成本仓库可执行管线。阶段→执行者映射：
> ①笛卡尔积生成(广度) = 生成器(模板矩阵 × 实体库) ②可行性四步过滤(>90%) = 规则过滤+Agent
> ③数值/模拟快速验证 = 本机引擎/子代理 ④人类裁决 = human review sheet

## 四步过滤器(F1-F4)定义(每步砍一部分, 合计>90%)
- F1 良构性: 是否是可判定的具体语句(对象明确/量词明确/判据存在)? 伪命题=空泛口号/多义未定/无判据。
- F2 可验证性: 是否有本机可运行的判定器/模拟器/数据?(数值/枚举/表/语料统计) 无 → 降级 blueprint。
- F3 初步新颖: 是否落在已知参照系内(OEIS/内置签名/文献命中)? 命中→已知归档; 未见→保留。
- F4 当务性: big_score H 与"是否结构新颖/深缝" → 保留高潜力者进验证。

## 阶段产物与角色
1. `gen_matrix()`: [方向模板]×[实体载体] → 候选命题(语句+路由)
2. `filter_f1_f2_f4()` 规则层(快砍), F3 由参照系/后续
3. `verify_numeric()`: 调本机引擎(两数和/禁串/停时/偏置…) 产出 {真/假/悬置+证据}
4. `human_review`: 通过机器验证+未见文献的候选写入 review sheet, 供人类终审

## 度量
每轮记录: 生成数→F1/F2后剩→验证数→机器真数→"未见且真"数→提交人类数。
