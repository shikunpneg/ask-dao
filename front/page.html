Architecture

问道系统 / 结构

01
感知层 · Perception
接收多模态输入，理解用户意图与上下文，建立人与系统之间的第一层语义连接。
02
记忆层 · Memory
以人为中心的长期记忆结构，持续沉淀偏好、习惯与历史交互，让系统真正“认识你”。
03
推理层 · Reasoning
基于自进化与递归自我改进的推理引擎，在开放问题中持续逼近更优解。
04
执行层 · Harness
稳定可靠的运行框架，独立于具体模型与工具链，保证系统在真实环境中的确定性表现。
05
训练层 · Training
从数据构建到模型微调的全链路训练路径，支持自定义任务与领域适配。
06
应用层 · Application
面向科研、教育与产业场景，将能力封装为可调用的模型服务与智能体应用。

Open Questions

我们正在追问的问题

Q1
Personal Agent 如何真正“理解”一个人，而不是拟合一个人的历史行为？
当前以人为中心的记忆系统，大多停留在检索与复述层面。我们试图回答：什么样的记忆结构，才能让智能体做出恰当的主动关心与提醒？
Q2
递归自我改进（RSI）的终局是什么？现有的 score 能衡量它吗？
多数自进化工作本质上在过拟合某个评分。我们正在探索结合知识发现的评估方式，让 RSI 指向真正有意义的发现，而非分数上的自我循环。
Q3
是否存在一种独立于具体工具链的、稳定可靠的 Agent Harness？
从 Claude Code 到 Codex，Harness 的形态在不断变化。我们希望抽象出一套更底层的运行哲学，让系统在工具更迭中保持稳定。
Q4
AI 能否参与真正的科学发现，而不只是加速已有范式？
结合我们在 AI 与 Science 两侧的理解，我们相信完全由 AI 驱动的发现仍有局限。人与 AI 的协同，可能是通往新知识更现实的路径。

ABOUT

问道（Ask the Way）是一个探索以人为中心的记忆、递归自我改进与稳定 Agent Harness 的研究项目。我们相信，好的智能体不仅要能回答问题，更要能理解人、陪伴人、与人一起发现新的问题。
