原理 01

两条独立的路，两套成功标准

这是 v0.3.0 确立的架构，此后没有变过：判不了的不产出，两条路互不评判。

  • 问题路 · 产问题输入：外部信息（视觉 / 网页 / arXiv）· 日常问题 · 母题。流水：日常问题 → 前问题 → 科学问题 → 基础领域 → 问题树 → 领域融合。成功标准：答案成立 / 可判；每条问题必须带 route（判定方式）。
  • 想象路 · 产概念输入：词。流水：组词 → 拆词（深度 d）→ 还原造句 → 成段 → 解释。成功标准：语法正确 + 逻辑通畅 + 有推理判断——不是「有真实所指」。
  • 互不评判用问题路的逻辑（「这新吗」「有真实所指吗」）去判想象路的概念，是范畴错误。
  • 经验检索桥（可选）两条路可以各自单独跑，也可以选择过桥。过桥把组合词接到现实经验（维基双通道 + arXiv 回退 → 经验锚点），只做脚手架，不做裁判；过桥不改变任何判定，检索失败即退化为无锚点。

原理 02

什么算「新」：三层 + 三种形态 + 四道门

把「新」拆成可操作的门，而不是形容词。世界新问题至今 = 0，所以下面每一层都要标清是哪一层。

层 / 形态含义本 deck 里对应
K1 提出的问题机器提出、人没提过的候选问题问题路各域问题清单
K2 证据边界推进把人类讨论止步处往前推，可复核跨进制 10⁶ → 10⁸；账本更正
K3 归纳的规律从大量扫描里归纳出的可检验规律例外集有限、融合桥梁
「新」三形态①检索未见 ②结构可推 ③显著性证书①廉价，③才拦得住人
四道真门机器真判 → OEIS 实查 → 结构可推性 → 显著性证书novelty_gate
N0–N3N0 已知 → N1 大概率已知 → N2 疑似未见 → N3 世界新N3 = 0（诚实边界）
纪律：显著性 > 新颖性。任选参数的序列同样「检索未见」，只有显著性证书拦得住。

原理 03

问题从哪来：四种机制

前三种通用，第四种是领域包。「作者已提出」与「机器提出」必须分开标注——前者不算新问题。

机制抓什么来源标注
① 作者自陈未解open problem / remains unclear / 尚不明确作者已提出（不算新）
② 文本张力however / yet / inconsistent 处的分歧机器提出
③ 结构追问对结论句套四问：范围 / 反例 / 机制 / 定量机器提出
④ 领域包（如生物医学）10 类方法学缺口 + 从 HR/CI 直接算 E-value机器提出 / 作者已论及（分标）
实现：src/ask_dao_machine/paper.py · domains_biomed.py；产物每条带 evidence（原文句）与 route（判定方式）

dao v0.3 · 结果（一）

想象路的结果：6,642 个组合词走完五步

把「造词」做成一条可跑完的流水线：每个组合词都要经过五步，产出的是被理解的概念。

步做了什么产物
① 组词穷尽领域专业词组合：82 × 826,642 个组合词（word_fusion.json）
② 拆词（深度 d）问「它是什么」→ 拆实体 → 再问 → 可再拆？拆到原子概念（深度为变量）
③ 还原造句从底往上还原：嵌套 + 推理 + 判断 + 比较有推理判断的句子
④ 成段定义 → 判断 → 比较 → 结论一段自洽的理解
⑤ 解释指什么现象 / 机制 / 深问概念成立（判据：被理解）
原则：每个词都有意义，只不过是我们缺少想象力，无法理解它——因此不存在空想。纪律：成功标准是「解释」，不是「真实所指」。

验证：为什么这些算「新问题」

不靠措辞，靠四道真门 + 独立裁决。四道门全过才叫 N3，至今 0 条。

门怎么判这一代的结果
① 机器真判问题必须能被判定器结算（真 / 假 / 悬置）判不了的不产出
② OEIS 实查离线索引 399,061 条序列比对前缀未命中 ≠ 新（只写在「参照系未见」）
③ 结构可推性值能不能从更简单的结构推出来能推出来的降级
④ 显著性证书具名对象的不变量 + 参数扰动下保持唯一拦得住人的门
独立复核harness 换一套实现重算confirmed 13 · open 1 · rejected 1
结论：这一代产出的是候选问题与证据边界推进；世界新问题 N3 = 0，不粉饰。

问道 · 结果（二）

机器算出来的三个残余混杂门槛

要把这个效应解释成「没有效应」，未测混杂必须与暴露、结局同时达到多强的关联。

论文报告E-value按 CI 下界含义
HR 1.19（1.08–1.30）1.671.37未测混杂要与暴露、结局各自达到 RR≈1.67 才能把效应解释为零
HR 1.49（1.28–1.74）2.341.88最高风险组所需混杂强度更高，最难被混杂解释
HR 1.02（1.01–1.04）1.161.11替代分析那一条最脆：几乎任何微弱混杂都能解释掉
公式 E = RR + √(RR(RR−1))，用 HR 近似 RR，只在结局不常见时成立（本文 CKD 发病率低）。

验证：为什么这是新问题、为什么算新知识

同一个结果要分别过两道验证，标准不同、话也不能混着说。

问怎么验证本次结论
为什么是新问题① 不是作者自陈（is_author_stated）② 带判定方式（route）③ 原文句可核对 ④ 主题作者是否已论及单独标注（author_touched）29 条追问中 23 条的主题作者已论及；6 条文中未见
为什么算新知识① 原文中是否出现过 ② 能否用论文自报的数字复核 ③ 是不是门槛而非结论原文里 E-value 出现 0 次；三个数任何人都能复核（1.67 / 2.34 / 1.16）
不主张什么世界新问题（N3）= 0；「文中未见」≠ 文献没有；不构成临床建议写在产出与网页里，不写在附录

诚实边界 · 收尾

这份结果不主张什么

每一条都写在产出里，而不是写在附录里。

  • 不主张世界新世界新问题（N3）至今 = 0；这里给的是候选问题与证据边界推进。
  • 不主张作者没想过生物医学 29 条追问里，23 条的主题作者已在文中论及；机器加的是可判形式（滞后分析、E-value 门槛、RERI、回归校准…），不是话题本身。
  • 不主张文献没有「文中未见 / 参照系未见」只表示索引里没有；OEIS 是沉默代理，不是文献门。
  • 不构成临床建议HR 与 E-value 是流行病学量的换算，不能推出任何用药、摄入或诊断建议。
  • 想象路不接受真伪评判概念的成功标准是「被理解」；用「这新吗」去判想象路，是范畴错误。
对应站点 §诚实边界 与 README §诚实边界 的同一条纪律。
