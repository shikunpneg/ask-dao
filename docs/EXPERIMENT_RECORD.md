## 第 0 部分 起点：理论主张（用户）
1. 三能力：推理验证 / 联想 / 大胆猜想；
2. 理论：领域由"母题"组成；问题早期都是真伪问题，像树一样分支；跨域融合碰撞产生新问题；
3. 三步：日常疑问 → 领域结构化（发现真问题）→ 思想实验验证 →（后修正：真伪判定为主，可行性后置）→ 扩展成理论；
4. 目标：能制造科学问题/知识的机器；后来明确：**要产出真实的新问题**。

## 第 1 部分 理论审计（语料派）
- 语料：爱思唯尔科学哲学手册 8 种 14 册、梯利《西方哲学史》、哲学100问、北大《中国哲学史》第2版、库恩《科学革命的结构》、斯特雷文斯《知识机器》、波普尔《科学发现的逻辑》等。
- 方法：EPUB→文本（pandoc/自写提取器）→ 分片派子代理精读 → 取证报告 A/B/C/D/E/F + 汇总。
- 关键裁决：
  * 母题论：弱版成立（结构/机制/对称/功能这类生成程序），强版（封闭母题库）被哥德尔/科恩/塔斯基否决；
  * "所有问题早期都是真伪问题"：作为**问题语法形式**成立，但真值悬置是常态；判定须分域（形式/经验/规范）；
  * 思想实验=概念裁决（一致性/可能性），不给经验真值；
  * 发现（第一猜想）不可程序化，但"反例→新问题"可程序化（机器甜区）；
  * 领域定义=宪章五件套；解释类型是最硬分界。
- 产物：`_theory/definitions_audit.md`、`basic_domains.md`、`plan_v2.md`、`synthesis_理论审查报告.md`、report_A–F。

4. **诚实纠错（≥5 次，每次都让候选缩水）**：
   * P4 判定 bug（三角+孤立点误判）→ cograph 修正后命中 A006351；
   * 置换检验分母 bug → p 从 1.0 纠为 **0.0002**（数学×人文句长差异显著）；

## 第 7 部分 总结论（诚实）
- **世界新问题 = 0**（三重门槛：机器可真判 + OEIS/文献未见 + LLM/人工不排除，无一项通过）；

## 第 8 部分 Claude Code 接手轮（R22）：三项整改 + 一处纠错 + 一个可判雏形

### 8.1 纠错：S2 "表观有界" 结论作废
旧记录（R15）称 "p∈{3,5,7} 奇 q≤71 停时单调爬升，表观有界但未证"。复算发现两处方法学缺陷：
1. **运行最大值同义反复**：`max over q≤Q` 对 Q 单调递增是集合扩张的必然，不含任何信息；
2. **窗口过窄**：旧扫描仅到 Q=71（奇 q 只有 36 个）。

新工具 `tools/s2_bounded.py` 改用**滑窗统计量**（窗口内 max / 中位）、存活率与无截断计数：

| p | 窗口中位（q 中心 100→4900） | 存活率 | 幂指数 a | 裁决 |
|---|---|---|---|---|
| 3 | 289→321→367→430→587 | ≈1.000 | 0.179 | **无界（随 q 增长，≈q^0.18）** |
| 5 | 366→356→362→353→347 | 0.93 | −0.013 | 窗口内有界（持平） |
| 7 | 134→139→135→130→132 | 0.86 | −0.008 | 窗口内有界（持平） |

- p≥5 存活率 <1：部分轨道未在截断内到达 1，故其"有界"是**条件于到达 1**的，非全局证明。
- **后果**：S2 的 OEIS"双未见 ×7"建立在截断敏感的统计量上 → 候选应降级，不应继续作为 M4 的支撑。

### 8.2 整改 A2：真 F1 良构门槛
旧门槛 `len(statement) >= 20` 形同虚设。新 `tools/cross_md_v4.py::f1_check` 要求结构化三元：
**obj（明确对象）+ quant（参数量词域，须含区间/集合）+ crit（判定判据）**，且 obj 不得为占位符。
- 结果：454 条笛卡尔组合，**0 条过门** —— 自动短语矩阵 100% 是空壳（只有对象碎片，无量词域、无判据）。

### 8.3 整改 A1：三域交叉去名义化（本轮核心）
对 v3 旧产物做名义审计：**三域候选 50 条，其中真三域 0 条，名义三域 50 条**（第三域只挂在句尾，
F2 只按前两域匹配 handler，第三域从未进入计算）。

新 `tools/tri_verifiers.py` 建立真三域验证器，**验收标准 = 参数敏感性**（扰动第三域参数，输出必须变化）：

| 三域组合 | 第三域参数 | 结果随参数变化 | 关键数值 |
|---|---|---|---|
| 生物选择 × 数学递推 × 信息熵下界 | h_min | ✓ | p*: 0.987→0.9468→0.8539→0.684；h_min>1bit 不可行 |
| 语言文法 × 工程冗余 × 信息信道 | r | ✓ | 有效率 1.0→0.909→0.833→0.667→0.5；最小冗余 r*=0.883 |
| 心理信念 × 数学迭代 × 信息信道 | q_hat | ✓ | 后验 0.643→0.800；临界样本量 T*=160→20 |
| 物理对称 × 数学极值 × 信息熵 | n | ✓ | 熵 2.585→8.459；对称约束熵代价 → log2(n) |

- **敏感性检验抓出 1 个自身的名义验证器**：心理验证器在 T=5000 时所有 q_hat 都收敛到 1（第三域名义）；
  改为有限证据（T=10）+ 临界样本量 T* 后才真正负载。这说明检验机制有效，不是走过场。
- 4/4 通过敏感性 → **真三域候选从 0 增至 4**（此前 v3 的 50 条全部为名义）。

### 8.4 整改 A3：矩阵质量分层
454 条组合 → (i) 可判 8（4 个两域 + 4 个真三域）/ (ii) 需建验证器 3 / (iii) 空壳 454（矩阵全数）。

### 8.5 B5：把"言不尽意"做成可判雏形
把哲学断言重写为**最小文法类分离问题**：给定"意义模式"（形式语言 L），判定其最小文法类；
若 L 需要 ≥ 上下文敏感文法，则"有限的'言'（表层语法）不能穷尽该'意'"。
判定器 `tools/p_A5_yanyi.py` = 正则泵引理穷举 + CFL 泵引理穷举（**机器验证**，非关键词）：

| 意义模式 | 判定 | 与预期 |
|---|---|---|
| a^n b^n（嵌套依赖） | ≥CFG 且非正则 | ✓ |
| a^n b^n c^n（双重嵌套） | ≥上下文敏感（非CFG，机器验证） | ✓ |
| a^n b^n c^n d^n（三重嵌套） | ≥上下文敏感（非CFG，机器验证） | ✓ |
| ww（跨序列复制/交叉依赖） | ≥上下文敏感（非CFG，机器验证） | ✓ |
| Dyck（一般嵌套） | ≥CFG 且非正则 | ✓ |

- 诚实标注：组件理论（Myhill-Nerode / 泵引理）**均为经典 N1**；本脚本贡献是把"言不尽意"从
  哲学断言变成**可判分离问题**并给出机器判定器，**不主张理论新意**。

### 8.6 本轮结论
- 修掉 3 个把"名义"当"成果"的缺陷（F1 空壳门 / 名义三域 / 未分层矩阵），推翻 1 个错误结论（S2 有界）；
- 真三域候选：0 → 4；可判分层：0 → 8（可判）+ 3（需建验证器）；
- **N3 仍 = 0，世界新问题仍 = 0**；本轮是**诚实性/正确性**收益，不是新颖性收益，不得粉饰。
