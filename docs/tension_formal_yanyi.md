# 言不尽意 × 语言熵率 —— 形式化雏形（P-A.A3 产物）

## 候选原始句
"若意义状态集合的复杂度超过任何有限文法可达熵率上限，'言不尽意'是否得到一个精确模型？"

## 形式化拆分(把概念命题切成可判子命题)
设 Σ 有限字母表, G 有限生成文法(正则/无歧义CFG), L(G)⊂Σ*, h(G)=熵率(每符号 nats/bit)。

**子命题1(可判·数学)**：对任意有限文法 G, h(G) ≤ log₂|Σ|(bit/sym)；且存在无歧义文法达到上界(二元 Dyck: h=1bit/sym=log₂2)。
- 机器证据(ling 引擎, 已复核): 禁bb 正则 h=logφ≈0.48nats; Dyck(无歧义CFG) 渐进 h=ln2=1bit/sym → 达到字母表熵上界。
- 判: 真(已知定理+机器复核)。

**子命题2(建模·开放)**：定义"意义状态空间" M，使"M 不可嵌入任何有限生成语言 L(G)（保结构映射不存在）"可判 —— 需要先建模 M。
- 现状: 无 M 的公认模型 → 该子命题是**新的前问题**(不是已解问题): "意义状态空间如何建模才使可嵌入性成为可判问题?"
- 候选模型方向: M = 某结构类上的可定义集(模型论) 或 不可压缩状态(Kolmogorov); 判定=该集是否 r.e. 可枚举。

## LLM 判(操作层)
- 子命题1: 已知-复核(N1)。
- 子命题2: **N2(弱)——不是"言不尽意已被熵率证明"，而是"需要先建立 M 的可判建模"这一前问题**；文献检索未见此建模路线(言意线均为诠释学)。
- 结论: 候选从"哲学断言"降级/重定位为**可推进的建模前问题**——比原句更有用、可继续攻。
