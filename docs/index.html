Architecture

问道系统 / 结构

01
感受模块
接收视觉 / 听觉 / 网络文本，转成结构化观测，长出日常疑问。
02
问题制造模块
反例驱动 · 问题树 L0–L5 · 全领域并行扫描 · 领域融合 · 新颖性门。把困惑变成可判的问题。
03
执行模块 · AI4S
对问题清单独立验证、求解，裁决回灌。标准：答案成立 / 可判。
04
想象模块
组词 → 拆词(深度d) → 还原造句 → 成段 → 解释。把词变成被理解的概念。
05
问题路 · Problem Path
产问题，需解决。输入：外部信息 / 日常问题 / 母题。出口：可判问题清单。
06
想象路 · Imagination Path
产概念，需解释。输入：词。出口：被理解的概念 / 理论。两条路互相独立。

ABOUT

问道（ask-dao-machine）是一台**知识发现机器**。已有的 AI4S 生态擅长解决问题，却缺"问题从哪来"这一环——能定义问题、提出问题的系统，远比能解题的系统稀缺。问道补的正是这一环。
