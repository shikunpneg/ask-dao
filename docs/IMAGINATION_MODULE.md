# 想象模块（第二条路）—— 完整总结

> **不可动摇的原则**：每个词都有意义，只不过是我们缺少想象力，无法理解它。
>
> 因此：**不存在空想**。不允许用"是否有真实所指/是否已研究/是否有意义"来判断想象路的概念——
> 那是问题路的逻辑。想象路要做的，是想出理解。

---

## 五步流程

```
① 组词 → ② 拆词(深度d) → ③ 还原造句 → ④ 成段 → ⑤ 解释
```

### ① 组词
- 穷尽领域专业词的组合：82 词 × 82 = **6642 个组合词**
- 例：文学×工业化 → "文学工业化"（用户举例，几乎前所未有的观点）
- 工具：`tools/engines/word_fusion.py`、`tools/core/word_understand.py`

### ② 拆词（深度 = 变量 d）
- 看到词（如"记忆调性"）→ 问"**它是什么？**"（疑问句）
- 拆实体：**记忆** + **调性**
- 再问：什么记忆？（过去影响现在）什么是调性？（围绕主音组织）
- **是否可再拆？** 过去可拆（时间/事件）、影响可拆（因果/塑造）……
- **何时停 = 深度变量 d**。d 可调（d=0 一层，d=自然深度拆到原子概念）
- 实验发现：概念树有**自然深度**（如"记忆调性"=3），d 超过即饱和
- 工具：`tools/research/depth_sentence.py`、`tools/research/depth_batch.py`

### ③ 还原造句（嵌套、推理、判断、比较）
拆到底后**从底往上还原**。关键是**不成括号拼凑**，而要有：
- **嵌套**：每层用自然语言完整句子表达，原子概念融入句子
- **推理**：据此可以推断……
- **判断**：失忆是哪一种记忆调性？（用概念解释现象）
- **比较**：失忆症是**疾病**，而记忆调性是**正常现象**（用对立概念划边界）
- 工具：`tools/research/reconstruct.py` → `reconstruct_sent.py` → `reconstruct_judge.py` → `reconstruct_compare.py`

### ④ 成段
段落结构：
```
定义(是什么) → 判断(据此可以推断) → 比较(但必须区分) → 结论(因此)
```

**范例（记忆调性）**：
> 记忆调性，若是一个真实概念，指的是：记忆不是平铺的档案，而是围绕某些"主音"组织。
> **据此可以推断**：失忆不是记忆的"丢失"，而是记忆的"调性崩溃"——主音被摧毁，记忆散落失序。
> **更进一步**：记忆有调性，恰恰保证了人类能更高效地分配精力——只记住主音和相对位置，是记忆的压缩策略。
> **但必须区分**：失忆症是一种疾病，而记忆调性是正常现象——正如"心律失常"是病，"心跳有节律"是正常。
> **因此**，记忆调性回答"正常记忆如何组织"，失忆症回答"组织被摧毁时发生什么"。

### ⑤ 解释
- 对成段结果**再解释**：它指什么现象、内在机制、深问
- 工具：`tools/research/understand_deep.py`

## 与其他模块的关系

- **想象路**（本模块）：产**概念**，需**解释**，标准 = 解释语法正确 + 逻辑通畅 + 有推理判断
- **问题路**（②制造→③执行）：产**问题**，需**解决**，标准 = 答案成立
- 两条路**独立**，各有各的成功标准。**不许用问题路逻辑（真实所指/是否新）评判想象路概念。**
