# 什么算新知识

> 这个定义被反复重订过。最终确立：**三层问题发现模式**与**两种新知识产生方式**。

---

## 总览

```
三层问题发现模式          两种新知识产生方式
  K1 提出问题   ──────→ ① 提出新问题
  K2 推进解答   ──────→ ② 旧问题的新解答
  K3 归纳理论   ──────→ （第三种，机器只能部分做到）

                          ① + ② = 新知识
```

---

## 两个前提命题

### 命题一：提出新问题，本身就是新知识的第一步

爱因斯坦的"追光思想实验"不是解答，是问题——但它改变了物理。
哥德巴赫猜想的**提出**（1742）比它的任何进展都更早地定义了一个领域。

> AI4S 生态里，**能解决问题**的系统一抓一大把；
> **能定义问题、提出好问题**的系统稀缺得多。

### 命题二：旧问题的新解答，也是新知识

这是机器最擅长、最扎实、最确定的一类产出：
不必造人类未知的问题，只要把已知问题的**证据边界推进一个数量级**。

例：MathOverflow #250504 讨论"n = 回文数 + 素数"只到 ~10⁶；
机器推到 **10⁸ 零例外**，并用两种独立实现交叉验证。这是**新知识**。

## 三层知识模型

| 层 | 是什么 | 机器能做到 | 本项目实例 |
|---|---|---|---|
| **K1 提出问题** | 把日常困惑/知识裂缝，改造成**精确可判**的问题 | ✅ | "言不尽意" → 最小文法类分离问题 |
| **K2 推进解答** | 对**旧问题**给出更强证据 / 更大验证边界 | ✅ | `回文数+素数` 10⁶ → **10⁸ 零例外** |
| **K3 归纳理论** | 从数据里归纳出**可验证的普遍律** | ⚠️ 部分 | 格律熵 = n/2 + 1 bit |

> **重要**：早期本项目只用"K3 且人类未知"（N3）当唯一及格线，
> 于是把 K1/K2 的实际产出当成了"不够格"。这是错的。

---

## "新"的三种形态

```
陈述新  —— 这个句子没出现过
          （廉价：换个说法就算新）

对象新  —— 这个结构没被研究过
          （可造：但查证后常被占领）

接口新  —— 问题站在刚被解锁的节点上
          （稀缺：科学史大问题的真实产地）
```

### 关键洞察

> 真正的大问题不是"没人问过"，而是"**问不出来**"——
> 它在某个节点之前，**既没有问它的动机，也没有答它的工具**。

例：

| 大问题 | 为什么之前"问不出来" |
|---|---|
| 光速问题 | 迈克尔逊-莫雷实验之前，没有动机 |
| 元素周期表 | 原子量测量之前，没有工具 |
| 回文+素数的 10⁸ 结构 | 机器推到 10⁸ 之前，看不见 |

## 为什么"检索未见 ≠ 新"

手头的参照系只有两个：

1. **OEIS**（393,600 条整数序列，离线索引）
2. **公开检索**（有限）

于是：

- 一个序列"OEIS 未见"，可能只是因为**它没有数学价值所以没人收录**；
- 一个概念"检索未见"，可能只是因为**没人用这个说法**。

**真正的文献门需要人 / 联网**——离线做不到。

---

## 为什么"显著性 > 新颖性"

实测（R23，六策略对照）：

| 策略 | OEIS 未见率 |
|---|---|
| 经典组合计数 | 0% |
| 参数族停时表 | 0% |
| 模迭代轨道 | 0% |
| **任选参数（无意义序列）** | **100%** |
| 机器自己的模板 | 0% |

最后的**任选参数**策略说明：

> **过 OEIS 门是廉价的。** 一条无意义的随机序列同样"OEIS 未见 + 结构不可推"。

唯一拦得住噪声的是**显著性证书**：

```
候选必须附带：
  (a) 一个具名对象
  (b) 一条不变量
  (c) ≥2 个"任意选择"的扰动变体，及该不变量在各变体下的取值
要求：不变量在扰动下保持不变（含容忍度与相对离散度）
```

## 对想象路的例外

想象路的产出是**概念**，不是问题。它的标准是**解释**：

```
语法正确 + 逻辑通畅 + 有推理判断
```

**不许**用"是否有真实所指""是否已研究""是否新"去评判想象路的概念——
那是问题路的逻辑，是**范畴错误**。

> 想象路的原则：每个词都有意义，只不过是我们缺少想象力，无法理解它。
