## 一句话结论

**世界新问题（N3）= 0 条。** 真正站得住的产出有两类：**K2 证据边界推进**（把人类讨论止于 10⁶ 的
跨进制问题推到 10⁸，并给出 15 个进制的例外分类），以及**一批真的、机器自己答不尽的问题**。
其余产出的价值需要人判断——机器只主张到"算出来了、参照系里没记录、显著性检验通过"为止。

## 一、K2 证据边界推进（最扎实）

### 1.1 命题与观察

> **命题 P(b)**：对每个整数 n ≥ 4，存在一个 base-b 回文数 p 与一个素数 q，使 n = p + q。
>
> **更强的观察（机器规模化算出）**：对 b ≥ 4，**例外集有限且很小**。

### 1.2 完整 harness 裁决表（`tools/ai4s_harness.py`）

N0 = 5×10⁶ 与 N1 = 10⁷ 两次扫描，看例外集是否**汇合**：

| base | 例外数（到 5×10⁶） | 例外集 | harness 裁决 |
|---|---|---|---|
| 2 | 2,147,887 | 持续增长、贴边界 | **rejected**（出现新例外 5000001…） |
| 3 | 68 | [78, 88, 100, 118, …] | open（例外多、仍在冒） |
| **4** | **5** | {35, 255, 515, 1855, 4345} | **confirmed** |
| **5** | **4** | {66, 418, 448, 1266} | **confirmed** |
| **6** | **1** | {1855} | **confirmed** |
| **7** | **0** | ∅ | **confirmed（零例外）** |
| **8** | **0** | ∅ | **confirmed（零例外）** |
| **9** | **1** | {124} | **confirmed** |
| **10** | **0** | ∅ | **confirmed（零例外）** |
| **11** | **1** | {126} | **confirmed** |
| **12** | **0** | ∅ | **confirmed（零例外）** |
| **13** | **1** | {126} | **confirmed** |
| **14** | **1** | {540} | **confirmed** |
| **15** | **0** | ∅ | **confirmed（零例外）** |
| **16** | **1** | {539} | **confirmed** |

**15 个进制中：13 confirmed（含 5 个零例外）· 1 open（b=3）· 1 rejected（b=2）。**
`confirmed` 的含义是：**N0 → N1 例外集汇合、无新例外**——是数值汇合，**不是证明**。

### 1.3 边界推进的三个关键数字

| 项目 | 机器结论 | 参照 |
|---|---|---|
| base 10 | 推到 **10⁸ 零例外**，**两种独立实现交叉验证** | 人类讨论此前止于 ~10⁶；MathOverflow #250504 曾怀疑 999999 是反例 |
| 单例外进制 | 推到 **3×10⁷ 完全稳定**（例外数不变） | b9=124 · b11=126 · b13=126 · b14=540 · b16=539 |
| 反向检验 | 两回文数之和的例外密度 **26.7%** | 与 Zakharov 2024 定理方向一致 |

**结构观察**（写进 `docs/CONJECTURE_PALBASE.md`）：b11 与 b13 的例外**同为 126**；b14 与 b16 的例外
539/540 **相邻**——提示"两个回文都差一点够不到"的留隙结构。

### 1.4 配对集命题（`out/demo/grown_motifs.json`，共 21 条）

由"母题 × 母题"配对生成、机器实测到阈值的命题：**confirmed 13 条 · needs_extend 7 条 · hypothesis 1 条**。

| 例 | 命题 | 实测阈值 |
|---|---|---|
| GM000 | 质数 × 奇合数 配对集覆盖 | 12 |
| GM001 | 质数 × 平方数 | 7746 |
| GM004 | 质数 × 回文数 | 6（阈值之后无例外） |

每条都带 `probe.complete` 与 `fails_head`（阈值之前的例外）。

### 2.2 反例驱动：机器**自己答不出**的问题（最有辨识度的一类）

例（原文取自记录）：

- 偶数 n 写成「半素数 + 平方数」的例外集在 [6,40000] 内共 6 个，最大者 108 —— **是什么刻画了这个例外集？**
- 偶数 n 写成「奇合数 + 三角数」的例外集共 13 个，最大者 662 —— **是什么刻画了这个例外集？**
- 偶数 n 写成「奇合数 + 半素数」的例外集共 12 个，最大者 38 —— **是什么刻画了这个例外集？**

这一类之所以重要：机器能**枚举出**例外集，却**刻画不出**它的结构；问题因此是"真的、且机器自己答不出"。

### 2.3 科学史挖出的真未解（人类已知未解，机器只是挖出来）

奇完全数 · 曲线与直线比较 · 欧拉-哥德巴赫 …… 来源 `out/demo/scihist_open.json`（A 级"自我承认的未知"）。
**这些不算新知**——是机器把人类已知的未解系统地找齐。

### 2.4 唯一走完四门、交人类裁决的候选

偶数 n = **(Harshad 数) + (平方数)** 的例外集（120 个）。机器侧证据：

| 门 | 结果 |
|---|---|
| 机器真判 | 精确枚举；平均表示数 14.5 |
| 机器无法描述 | 补 36 个模类后仍 class_fit=None |
| 参照系未见 | OEIS（393,600 序列）例外集本体与累计计数均未命中 |
| 显著性 | 置换零模型 λ=16.12 → 预测 0.001，实测 120（≈3.04×，p≈0.016；早期 Poisson 版错报 1.2×10⁵ 倍） |
| 文献 | 检索 "Harshad + square" 无结果 |

裁决单：`docs/human_review_candidate.md`。**机器不得自称新问题。**

## 四、想象路：概念（标准是"解释"，不是"真实所指"）

**核心原则**：每个词都有意义，只不过是我们缺少想象力，无法理解它 —— 因此不存在空想。

### 4.1 概念（`out/demo/imagination_deep.json` / `sentence_batch.json`）

| 概念 | 本质判断 | 可检验问题（机器自己提出） |
|---|---|---|
| 意识拓扑 | 意识是内在表征空间的结构/几何 | 用句/文/图的表征状态替换，认知结构不变性与否相同？ |
| 记忆压缩 | 记忆是围绕主音组织的压缩 | "痕迹"的最小单位是什么？ |
| 语义市场 | 语义随使用供需变化 | 语义漂移是否有守恒量？ |
| 责任催化 | 问责是最强催化剂 | 责任爆炸的临界点由什么决定？ |
| 正义测度 | 正义可被度量 | 不同正义观的测度是否可比较？ |

### 4.2 规模与落地检验

| 项目 | 数字 |
|---|---|
| 组合词诠释（`word_interpret.json`） | 6,642 条，每条 ≥3 种诠释 |
| 词的认真理解（`word_understand.json`） | 6,642 条 |
| 跨域造词（`word_fusion.json`） | 6,642 条，带 `judge_route` |
| 落地检验（`imagination_batch_verify.json`） | **grounded 320 / ungrounded 56**（376 个概念，320 个在真实领域有支撑） |
| 深拆（`depth_sentence.json`） | 概念按深度 d 拆到原子概念 |

> 注意纪律：**"有真实领域支撑"不等于"新"或"真"**——想象路只对"解释是否成立"负责。

### 5.1 跨域母题（`out/demo/derived_motifs.json`）

**纪律**：无共享结构的配对只是空洞笛卡尔积——所以每条都必须落到一个具名框架。

### 5.2 三域仿真（信念修正 × 迭代 × 噪声信道，`cross_md_belief.json`）

| 信道容量 C | 正确模型 | 低估噪声 | 高估噪声 | 低估时的偏差 |
|---|---|---|---|---|
| 0.0072 bit | 收敛 | **0.5（完全不学习）** | 收敛 | 0.5 |
| 0.029 bit | 收敛 | **0.5（完全不学习）** | 收敛 | 0.5 |
| 0.1187 bit | 收敛 | 收敛 | 收敛 | 0.0 |
| 0.2781 bit | 收敛 | 收敛 | 收敛 | 0.0 |
| 0.531 bit | 收敛 | 收敛 | 收敛 | 0.0 |
| 0.9192 bit | 收敛 | 收敛 | 收敛 | 0.0 |

**结论**：正确模型总是收敛；**低估噪声时，信道容量 ≲0.03 bit 段会塌成"完全不学习"**，
容量再大一点即恢复；偏差随容量单调下降。这是本项目唯一一个"真三域参与"的仿真结果。

## 九、自纠错 12 次（每次让候选缩水，这才是对的）

| # | 错误 | 修正 |
|---|---|---|
| 1–5 | P4 判定 bug / 置换分母 bug / X3 上界误标 / 偶 q 陷阱 / 阈值贴边 | 见 `docs/EXPERIMENT_RECORD.md` |
| 6 | `set` 迭代 + `break` 漏掉较小加数 → 假造 16166 例外 | 改排序遍历（与已知 fail_count 吻合） |
| 7 | 类包含检查跳过猜想自身两类 → 漏掉关键刻画 | 修复后升为"候选刻画" |
| 8 | 例外稠密度守卫缺失 | 加 `max_exc_density=5%` |
| 9 | 蕴含去重连错三轮（跨语境 / 强度轴 / 方向不可分） | 改等价类去重 |
| 10 | **Poisson 零模型错 5 个数量级**（"1.2×10⁵ 倍" → 实际 3.04×，p≈0.016） | 改**置换零模型** |
| 11 | "机器无法描述"其实是类库太薄 | 补避型 + 二次剩余原语 |
| 12 | 差点把"孤立顶点自由度翻倍"当"二部图有阻挫" | 排除平凡自由度后重报 |
