## 四、失败与负结果（同样重要）

| 负结果 | 结论 |
|---|---|
| 六策略对照 | 机器自己的模板 OEIS 未见率 **0%**；任选参数 100%（说明门是廉价的） |
| 300 组合跨域扫描 | 全部落在已知类（Schnirelmann 密度 / 稠密推论） |
| 全方位扫描 462 组合 | 194 个"OEIS 未见"中，绝大多数无数学价值 |
| 领域融合 702 对 | 144 个有结构桥梁；"数学×艺术" 26 个里已知 20 个已占领 |
| 多完全数奇数版 | 到 2×10⁶ 无解——但是**已知更强下界的弱化** |
| Track 5 语料 | 9 个语料全部服从门泽拉特律（0 例外）→ 产不出问题 |

## 五、自纠错记录（12 次，每次都让候选缩水）

| # | 错误 | 修正 |
|---|---|---|
| 1–5 | P4 判定 bug / 置换分母 bug / X3 上界 / 偶 q 陷阱 / 阈值贴边 | 见 EXPERIMENT_RECORD |
| 6 | `set` 迭代 + `break` 漏掉较小加数 → 假造 16166 例外 | 改排序遍历（与已知 fail_count 吻合） |
| 7 | 类包含检查跳过猜想自身两类 → 漏掉关键刻画 | 修复后升为"候选刻画" |
| 8 | 例外稠密度守卫缺失 | 加 `max_exc_density=5%`（回溯纠正 R25） |
| 9 | 蕴含去重连错三轮（跨语境 / 进制作强度轴 / 方向不可分） | 改等价类去重 |
| 10 | **Poisson 零模型错 5 个数量级**（"超 1.2×10⁵ 倍"→ 实际 3.04×） | 改**置换零模型** |
| 11 | "机器无法描述"是类库太薄的产物 | 补避型 + 二次剩余原语 |
| 12 | 差点把"孤立顶点自由度"当"二部图有阻挫" | 排除平凡自由度后报 |

> **自纠错优先**是项目纪律：历史上每次自纠错都让候选缩水，**这才是对的**。
