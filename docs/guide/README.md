## 一句话

```
问题路：外部信息 / 日常问题 / 母题  →  科学问题  →  问题树  →  领域融合  →  AI4S 求解
想象路：词                        →  组词 → 拆词 → 还原造句 → 成段 → 解释
```

两条路**互相独立，各有各的成功标准**：

- 问题路的标准是 **答案成立 / 可判**
- 想象路的标准是 **解释语法正确 + 逻辑通畅 + 有推理判断**

> ⚠️ 不许用问题路的逻辑（"这有真实所指吗""这新吗"）去评判想象路的概念——那是**范畴错误**。

---

## 想象路的核心原则

> **每个词都有意义，只不过是我们缺少想象力，无法理解它。**

因此**不存在空想**。任何组合词（如"记忆调性""资本反馈""熵量子化"）都有意义，
任务不是判断"有没有意义"，而是**想出一个自洽的理解**。

详见 → [想象路手册](imagination-path.md)

## 诚实边界（先行声明）

1. **N3（世界新问题）至今 = 0** —— 不许粉饰。
2. **"检索未见" ≠ "新"** —— 参照系只有 OEIS + 检索。
3. **显著性 > 新颖性** —— 过 OEIS 门是廉价的。
4. 想象路的标准是**解释**，不是真实所指。

详见 → [诚实边界](honesty.md)
