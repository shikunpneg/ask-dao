# 术语表

## 两条路

| 术语 | 定义 |
|---|---|
| **问题路** (Problem Path) | 产**问题**的路。输入：外部信息 / 日常问题 / 母题。标准：答案成立 / 可判 |
| **想象路** (Imagination Path) | 产**概念**的路。输入：词。标准：解释语法正确 + 逻辑通畅 + 有推理判断 |

## 知识分层

| 术语 | 定义 |
|---|---|
| **K1 提出问题** | 把日常困惑/知识裂缝改造成**精确可判**的问题 |
| **K2 推进解答** | 对旧问题给出更强证据 / 更大验证边界 |
| **K3 归纳理论** | 从数据里归纳出可验证的普遍律 |
| **陈述新** | 这个句子没出现过（廉价） |
| **对象新** | 这个结构没被研究过（可造，但常已被占领） |
| **接口新** | 问题站在刚被解锁的节点上（稀缺，大问题产地） |
| **问不出来** | 在某节点之前，既没有问它的动机，也没有答它的工具 |

## 新颖性分级

| 术语 | 定义 |
|---|---|
| **N0** | 明显已知（命中已知库 / 著名 / 已证） |
| **N1** | 大概率已知 / 标准推论可覆盖 |
| **N2** | 疑似未见（检索级）—— **不等于"新"** |
| **N3** | 强候选（机器真判 + 参照系未见 + 结构不可推 + 显著性证书）—— **至今 = 0** |

## 判定与门

| 术语 | 定义 |
|---|---|
| **判定路由** | 该问题由谁判（数值 / 轻量仿真 / 实验 / 形式证明） |
| **F1 良构** | 问题是否良构：须含**对象 + 量词域 + 判据**（不是"长度 ≥ N"） |
| **F2 可验证** | 是否有判定器 |
| **F3 参照系** | OEIS 实查：该结构是否已被记录 |
| **F4 证据门** | 当务分（H1–H10）是否**证据依赖**（不是关键词） |
| **显著性证书** | 具名对象的不变量 + ≥2 个任意选择扰动下保持 |
| **置换零模型** | 保持尺寸与奇偶分布，随机重抽，观察实测值在零分布中的位置 |

## 想象路术语

| 术语 | 定义 |
|---|---|
| **组词** | 穷尽领域专业词组合（82×82 = 6642） |
| **拆词** | 问"它是什么？"→ 拆实体 → 再问 → 可再拆？ |
| **深度 d** | 拆分深度**变量**；概念树有**自然深度**（超过即饱和） |
| **原子概念** | 拆到不可再拆的概念（叶子） |
| **还原造句** | 从底往上还原，用完整句子表达（**不是括号拼凑**） |
| **成段** | 定义 → 判断 → 比较 → 结论 |
| **概念论证** | 有推理和判断的段落，不是定义式描述 |

## 生成器 vs 过滤器

| 术语 | 定义 |
|---|---|
| **生成器** | 产出新候选的模块（反例驱动、组词、领域融合） |
| **过滤器** | 筛掉不合格候选的模块（F1/F2/F3/F4 门） |
| **教训** | 项目历史 **79% 代码在过滤侧** —— 每轮先问：这是生成器还是过滤器？ |

## 判决器 / 证据 / 其它

| 术语 | 定义 |
|---|---|
| **反例驱动** | 从**例外集的结构**长出问题（机器自己答不出的问题） |
| **诚实延伸探针** | 向扫描上界之外延伸，看是否还有新例外 |
| **例外稠密度守卫** | 例外 > 5% ⇒ 猜想本身为假，不产出问题 |
| **蕴含去重** | 弱形式被更强形式蕴含时，不重复计数 |
| **归约原语** | 检测例外是否在数位置换下不变（→ 归约到数位多重集） |
| **结构桥梁** | 领域融合的判据：对象携带的结构 ∩ 方法作用的结构 ≠ ∅ |
| **名义** | 只挂在句尾、未真正参与计算的要素（如"名义三域"）—— **不许当成果** |
