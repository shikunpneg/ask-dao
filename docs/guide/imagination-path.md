# 想象路手册

> **不可动摇的原则：每个词都有意义，只不过是我们缺少想象力，无法理解它。**

因此，**不存在空想**。任何组合词都有意义——任务不是判断"有没有意义"，
而是**想出一个自洽的理解**。

---

## 五步流程

```
① 组词 → ② 拆词(深度d) → ③ 还原造句 → ④ 成段 → ⑤ 解释
```

## ② 拆词（深度 d 是变量）

**方法**（以「记忆调性」为例）：

```
看到词：记忆调性
  → 问：它是什么？        （记忆是否有调性——即围绕中心组织？）
  → 拆实体：记忆 + 调性
  → 再问：什么记忆？        → 过去影响现在的方式
          什么是调性？      → 围绕一个主音组织其他音
  → 是否可再拆？
        过去可拆 → 时间 / 事件
        影响可拆 → 因果 / 塑造
        现在可拆 → 此刻 / 进行中
        主音可拆 → 中心 / 引力点
  → 何时停？= 深度变量 d
```

```bash
python tools/depth_sentence.py --word 记忆调性 --depth 3
python tools/depth_batch.py                # 9 个概念建树
```

**深度 d 的效果**：

| d | 拆到什么程度 | 「记忆调性」 |
|---|---|---|
| 0 | 一层 | 记忆是否有调性 |
| 1 | 拆实体 | 记忆 + 调性 |
| 2 | 拆实体本质 | 记忆→过去/影响/现在；调性→主音/音级/偏离/回归 |
| 3 | 拆到原子 | 过去→时间/事件；影响→因果/塑造；偏离→张力 |

**实验发现**：概念树有**自然深度**。「记忆调性」的自然深度 = 3，
d 超过即饱和（不再增长）。

## ③ 还原造句（嵌套 · 推理 · 判断 · 比较）

拆到底后**从底往上还原**。关键是**不能是括号拼凑**，而要有四样东西：

| 要素 | 说明 | 例 |
|---|---|---|
| **嵌套** | 每层用自然语言完整句子表达，原子概念融入句子 | "时间在单向流逝，记忆只能面向已经发生过的事情。" |
| **推理** | "据此可以推断……" | "据此可以推断：失忆是记忆的调性崩溃。" |
| **判断** | 用概念解释一个现象 | "失忆是哪一种记忆调性？" |
| **比较** | 用对立概念划清边界 | "失忆症是**疾病**，而记忆调性是**正常现象**。" |

```bash
python tools/reconstruct.py            # 基础还原
python tools/reconstruct_sent.py       # 句子化（不是括号拼凑）
python tools/reconstruct_judge.py      # 加推理判断
python tools/reconstruct_compare.py    # 加概念比较
```

**反例（不要这样）**：
```
记忆 = 过去影响现在(已发生(时间；事件)；改变(因果；塑造))   ← 括号拼凑，没有语义
```

**正例**：
```
所谓记忆，是过去影响现在的方式：过去由已发生的事件构成（这些事件是记忆的原料），
它借因果之链把过去与现在连起来，并在每一次回想中被重新塑造，而这一切总是发生在当下。
```

## ④ 成段

段落结构（**是论证，不是描述**）：

```
定义(是什么) → 据此可以推断(判断) → 更进一步(推论) → 但必须区分(比较) → 因此(结论)
```

**范例（记忆调性）**：

> 记忆调性，若是一个真实概念，指的是：记忆不是平铺的档案，而是围绕某些"主音"组织——
> 正如音乐围绕主音组织其他音。
>
> **据此可以推断**：失忆，不是记忆的"丢失"，而是记忆的"调性崩溃"——当记忆的主音
> （核心身份、自我叙事）被摧毁，所有围绕它组织的记忆便失去引力，散落失序。
>
> **更进一步**：记忆有调性，恰恰保证了人类能更高效地分配精力。因为我们不必记住每件事
> 的全部，只需记住"主音"以及经验相对主音的位置——就像记住一首歌的调性，就能推演大部分音符。
>
> **但必须区分**：失忆症是一种疾病，而记忆调性是正常现象——正如"心律失常"是病，
> "心跳有节律"是正常。
>
> **因此**，记忆调性回答"正常记忆如何组织"，失忆症回答"组织被摧毁时发生什么"。

## ⑤ 解释

对成段结果**再解释**：它指什么现象、内在机制、深问。

```bash
python tools/understand_deep.py
```

**例（资本反馈）**：
> 资本反馈研究的是财富的动力学：为什么财富分布是尖的、为什么会越来越尖、
> 以及什么机制能让它不那么尖。它把经济学（资本积累）与信息论（反馈回路）接在一起，
> **把"贫富差距"从道德话题变成"回路强度"话题**。
> 深问：是否存在一个"最优反馈强度"，使增长最大化而分布不过度尖化？

## 常见误区

| ❌ 错误做法 | ✅ 正确做法 |
|---|---|
| 说"这个组合没意义" | 想出一个自洽的理解 |
| 查资料验证"有没有真实所指" | **不查资料**，自己造句 |
| 要求解释"语法正确 + 逻辑通畅"之外的标准 | 只要求语法正确 + 逻辑通畅 |
| 用括号嵌套拼凑 | 用完整句子织成有语义的段落 |
| 只做定义式描述 | 加推理、判断、比较 |
