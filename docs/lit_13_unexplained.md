## 二、检索所得（按族）

### 族 1：两回文数之和（**跨进制**）—— 6 条
| 已有文献 | 覆盖什么 |
|---|---|
| Baxter–Cilleruelo–Luca：每个整数 = **3 个**base-g 回文数之和(g≥5) | **同进制**，3 项 |
| **Green 问题清单 Problem 95**：正比例整数能否 = 2 个 base-g 回文数之和 | **同进制**，2 项 —— 已问 |
| **Zakharov 2024**（arXiv:2402.10808）：多数整数**不是** 2 个 base-g 回文数之和，≤ X/log^c X | **同进制**，2 项 —— 已**否证** |
| Rajasekaran–Shallit–Smith：base 2/3/4 至多 **4 个**回文数之和 | 同进制，基数问题 |
| 同时回文（simultaneous palindromes）：P(2,3)=6643；Schimke P(a,a+1)=2a²+3a+2 | **同一个数**在两个进制下都是回文 —— **不是和** |

⇒ **检索结论：跨进制"两回文数之和"的和集问题，文献中未出现。**
   文献覆盖的是 (a) 同进制的和；(b) 同时回文（不同问题）。
   **但注意**：这不是"无人想到"，而是"同进制的兄弟问题极著名且刚被解决(2024)" ——
   跨进制版本很可能是**平凡**的（各进制回文数都稠密，和集自然近乎覆盖）。
   我们的数据也支持这点：例外仅 ~1.5%，且**低于**置换零模型预测（见 R33 对同类候选的纠正）。

### 族 2：多边形数 + 数位单调不减 —— 3 条
| 已有文献 | 覆盖什么 |
|---|---|
| Fermat 多边形数定理（Cauchy 证）：每个整数 = m+2 个 m+2 边形数之和 | 多边形数**内部**的和 |
| Legendre (1830)：>1792 的整数 = **4 个**六边形数之和；13 个例外(OEIS A007527) | 同上 |
| Meng–Sun：p₆(x₁)+p₆(x₂)+2p₆(x₃)+4p₆(x₄) 覆盖 | 带系数版本 |

⇒ 检索明确显示：**"数位单调不减"未被任何结果涉及**（原文："no information about numbers with
   nondecreasing digits"）。该组合在文献中沉默。
   **但诚实**：数位单调不减是一个"人为的十进制约束"，文献沉默更可能因为它**没人在意**，
   而不是因为它新。

### 族 3：数位和 × 完美幂 / 数位和 × 回文数 —— 4 条
- `base3数位和=5 + 完美幂`：例外含 4,6,8,…,18（小 n 段几乎全例外，说明**猜想在小 n 段为假**，
  是"小例外 + 大 n 成立"的结构）—— 这类在数论中极常见，大概率已知。
- `base2数位和=3 + base3数位和=5`（跨进制数位和）：检索未做；**但见下节的诚实判断**。

## 三、诚实判断（不粉饰）

1. **没有一条能升级。** 6 条跨进制回文数与 3 条多边形+数位单调属"文献沉默"，但：
   - 沉默的原因是**领地本身不值得**（人为约束），不是"刚被发现的门"。
   - 且 R33 已证明：同类"回文数对"候选在**正确的置换零模型下并不显著**（低于随机预测）。
2. **族 3 的 4 条**有"小例外 + 渐近成立"的形状 → 大概率是已知渐近定理的小例外（同 Chen 定理模式）。
3. ⇒ **这 13 条的真实价值**：它们证明机制电池**能挑出"不落在现有类库里"的东西**，
   但**挑出来 ≠ 有价值**。缺的是**问题级文献门**（离线做不了）与**领地价值判据**（人判断）。
4. 本轮**新增一条可机检判据**（见 R36）：候选的例外集若**低于**置换零模型预测，
   应直接降级 —— 防止"机器无法解释"被误当加分项。
