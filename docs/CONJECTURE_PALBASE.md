# 猜想：跨进制"回文数(b) + 素数"覆盖（R53 方向 3 落成）

## 命题（K1 层提出，机器发现 + harness 独立验证）

> **命题 P(b)：对每个整数 n ≥ 4，存在一个 base-b 回文数 p 和一个素数 q，使 n = p + q。**

**更强的观察（本机规模化算出的规律）**：
> **对 b ≥ 4，"n = 回文数(b) + 素数"的例外集有限且小。**

## 结构观察

单例外进制的例外值：b9=124, b11=126, b13=126, b14=540, b16=539。
- b11 和 b13 的例外**同为 126** —— 提示这个数（126）可能因为某种"两个回文都差一点够不到"的结构（126 附近两个进制的回文分布恰好留隙）。
- 539/540 相邻 —— b16 例外 539、b14 例外 540，相邻，可能是同构现象。

## 与已知文献的关系

- **base-10**："n = 回文数(b10) + 素数"是 MathOverflow #250504 的公开问题（未证未否）。
- **任意进制**：维基百科"回文数"词条**完全不涉及**"回文+素数"（已知的是三回文数和，Cilleruelo-Luca-Baxter 2018；开放问题是 Lychrel 过程与 Simmons 猜想，均不涉及素数）。
- **OEIS**：各进制例外集序列**未命中**。

## 诚实边界

1. **confirmed 是数值汇合，不是证明。** "例外有限"目前是强证据（10 个进制汇合），不是定理。
2. **"文献未见"基于维基 + OEIS + 检索** —— 需真正的文献门（MathOverflow/论文库）才能称"确认未见"。
3. **该命题的价值**（按 R49）：
   - 它是**机器规模化算出来**的（不是抄知识库的未知）；
   - 它有 **harness 独立验证**支撑；
   - 它比已知的 base-10 问题**更精细**（跨进制 + 例外汇合）；
   - 但**重要性未知** —— 需要人判断这个跨进制规律是否值得追。
