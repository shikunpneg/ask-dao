  - 网络文本: `tools/research/web_experience.py` (抓页->疑问) 有产出但质量待提升(arXiv侧边栏噪声)

## 修正（R75 用户）：两条路，不是四条线

**想象路（需要解释）** 与 **问题路（需要解决）** 是两条不同的路：

```
想象路: 造词 → 解释 → 理解               终点 = 被理解的词/理论(解释充分)
问题路: 日常问题→科学问题→解决            终点 = 被解的问题(答案成立)

①感受 → 问题路(②制造→③执行)   ← 问题的来路和解法
④想象 → 解释(不需要"解")        ← 概念的理解，独立成路
```

关键：**想象路的概念不是拿来"解决"的，是拿来"解释/理解"的。**
- 我 R73 的错误: 把想象概念(记忆压缩)直接交给执行模块"验证" —— 混了两条路
- 正确: 想象路产出概念, 它的终点是"这个词被理解"(有充分解释);
  问题路产出问题, 它的终点是"问题被解"(有答案)

所以:
- 想象路的质量 = 解释是否充分/自洽/有洞见
- 问题路的质量 = 问题是否被解决/可判

两条路各自独立, 各有自己的成功标准。
