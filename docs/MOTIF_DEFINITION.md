# 母题的定义与分层 (MOTIF_DEFINITION) —— 修正版

## 承认错误
v0.x registry 把"对象类(质数)/映射(σ)/规则(两项和)/域构造(奇偶)"混在同一张表,
粒度混乱 → "32 个母题"是一种误解性低估。本文件给严格定义, 并按层重建。

## 定义
**母题 = 一个可生成问题的基元**: 由三件套组成
1. **载体**(carrier): 机器可枚举/计算的实例(集合、映射、对象族、参数族……) —— 没有载体就不是母题,
   只是概念词。
2. **生成规则**: 该基元如何派生出候选问题(组合进句式 / 参数变异 / 与别基元配对)。
3. **判定路由**: 该基元参与的问题由谁判(数值判/轻量仿真/实验/形式证明)。

## 分层(粒度必须分清楚, 不再混装)
| 层 | 含义 | 数学例 |
|---|---|---|
| L4 域 | 一个大领域(不叫母题) | 数论/代数/分析/几何/拓扑/概率/组合/逻辑/动力 |
| L3 方向母题(研究纲领) | 该域内一种"问法族" | 分布与均匀性 / 表示计数 / 分类与不变量 / 极值与纪录 / 相变与临界 / 收敛与周期 / 可判定与复杂度 / 对偶与对称 |
| L2 算子/度量/映射 | 把对象变成数字/新对象 | σ,τ,φ, 熵, 距离, 谱半径, 梯度, 极限, 积分 |
| L1 对象族(载体) | 具体对象带生成函数 | 质数, 图族, 格点游走, 递推序列, 群族 |
| L0 结构本体 | 数学大厦的地基 | 群/环/域/序/度量/拓扑/测度/范畴 |

**判断"是不是母题"的操作判据**: ① 能直接实例化成 ≥1 个可判定问题(有载体); ② 与另一基元组合后产生新问题族(有生成规则); ③ 判定路由已知或可造。只满足①的=普通对象; 都不满足的=概念词, 不许进母题库。

## 对用户问题的直接回答
- "数学母题真的那么少吗": 不少。真问题是粒度混乱。按 L3 方向母题, 数学粗算 ≥8 域 × 5-10 方向 = 60+; 加 L2 算子/度量与 L1 载体族, 总 >200 个基元, 需逐层建载体与路由(工程, 非概念)。
- "其他域母题很少": 同因——每域都应按 L4→L0 各自建地图; 现 86 只是"登记占位"。
- "没有各种研究方向组合产生新问题": 方向级组合 = L3×L3(或 L3×L1): "方向A的典型问法"套"方向B的对象/算子"。这是**组合引擎的下一级**, 不再是对象类配对。
