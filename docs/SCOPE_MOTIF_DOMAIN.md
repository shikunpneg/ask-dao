## 一、母题 vs 一般科学问题

### 1.1 一句话区别
**问题是一个实例；母题是一个生成器。**
问题可以被回答；母题只能被**实例化**。问你"哥德巴赫猜想成立吗"是问一个问题；
问"两类稀疏集相加能否覆盖全偶数"是在用一个母题，它可以生成哥德巴赫、Chen、Estermann 一整族问题。

### 1.2 母题的构成（既有定义，`MOTIF_DEFINITION.md`）
| 要件 | 含义 | 缺了会怎样 |
|---|---|---|
| **载体** carrier | 机器可枚举的实例（对象族/映射/参数族） | 缺 ⇒ 只是概念词，不许进库 |
| **生成规则** | 如何派生候选问题（组合进句式/参数变异/配对） | 缺 ⇒ 是一次性问题，不是母题 |
| **判定路由** | 谁来判（数值/轻量仿真/实验/形式证明） | 缺 ⇒ 产出无法判定 —— **R23 实测：73% 产出因此进不了门** |

**操作判据**：① 能直接实例化成 ≥1 个可判定问题；② 与另一基元组合产生新问题族；③ 判定路由已知或可造。
只满足① = 普通对象；都不满足 = 概念词。

### 1.3 **新判据（R22–R33 实测补入，纸面理论得不出来）**
机器跑了 13 轮之后，发现上面三条**不够** —— 满足①②③ 的母题，产出仍可能全是垃圾。补三条：

| # | 判据 | 依据（实测） |
|---|---|---|
| **④ 必须能产出机器结算不了的问题** | 若母题的产出**全部能被生成它的机器立刻结算**，那是计算模板，不是母题 | R24：`add(stmt, judgement)` 同生 ⇒ 机器只提它已会答的；78% 代码在过滤侧 |
| **⑤ 产出必须有稀疏例外结构** | 若"例外"占 20%+，说明**猜想本身是假的**，无结构可言 | R26/R29：`回文数+平方数` 例外 24.7% ⇒ 假猜想，不是开放问题 |
| **⑥ 必须给出"机器无法描述"的**诚实**边界**（连同类库完备性一起报告） | 机器说"描述不了"可能只是工具太少 | R32→R33：补两个原语后 **39 个候选无一"无法描述"** —— 该门旧实现系统性不可靠 |

### 1.4 对照表
| | 一般科学问题 | 母题 |
|---|---|---|
| 粒度 | 实例 | 生成器 |
| 来源 | 通常人提出（观察/灵感） | 可枚举 + 可组合 |
| 可批量性 | 一次性 | 参数化批量（R30：406 对 → 57 候选） |
| 有无判定路由 | 常无 | **必须有**（否则进不了门） |
| 与新颖性的关系 | 直接争新 | 母题不新，**其远端子代**才可能新 |

## 二、哪些领域是真正的基础

### 2.1 判据（既有，`_theory/basic_domains.md` J1–J6）
J1 解释类型原创 · J2 判定族原创 · J3 问题句法原创 · J4 母题自足 · J5 对象不可还原 · J6 部门哲学建制。
**裁定规则**：J1 与 J2 各至少一项原创 + J3/J4/J5 多数 ⇒ 基础领域；靠借他域概念组装 ⇒ 复合领域。

### 2.2 裁定
| 领域 | 解释类型 | 判定族 | 裁定 |
|---|---|---|---|
| **逻辑** | —— | 中效（证明/模型/真值表） | **基础·元层**（一切域的"理"在此被审查） |
| **数学** | 证明-结构 | 证明/反证/**独立性** | **基础**（形式域原型） |
| **物理** | 定律-机制 | 效验-确证/证伪 | **基础**（经验域原型） |
| **生物** | **功能/选择**（近因-终极） | 选择-系谱证据/功能恰当 | **基础** |
| **心理/认知** | 机制（分解-定位-组织） | 实验对机制模型拟合 | **基础** |
| **信息与计算** | 信息流/计算说明 | 概念网络自洽+语义真值 | **基础** |
| **工程** | 设计（should→is） | 效用-规范满足 | **基础** |
| **伦理政治** | 规范/实践 | 行验/良知决 | **基础**（默认域外登记） |
| 化学 | 借物理+机制 | 实验-机理 | 候选·待补《化学哲学》 |
| 经济/统计 | 模型-效用 | 统计推断 | 候选·待补文献 |

### 2.3 直接回答你的两个问句
- **"是数学还是物理"**：两者都是基础，但**基础的方式不同**。
  数学是**形式域原型**（提供结构语言，其他域的结构词汇多借自它）；
  物理是**经验域原型**（提供"定律如何被确证"的范式）。不是二选一。
- **"是哲学还是生物"**：**哲学不是基础领域**，它是**元层**——逻辑（L0a）+ 各部门哲学（各域的宪章）。
  生物是**基础领域**（有原创解释类型：功能/选择）。

## 三、生物学能不能再被拆解成基础领域

### 3.1 能拆的部分
分子生物学 → 化学 → 物理；生物物理、生物化学都是活跃且成功的还原方向。

### 3.2 **不能拆的部分（关键）**
J5「对象不可还原」：**"为什么这个性状在种群中被维持"** 是**选择解释**，不是物理化学问题。
- 近因（proximate）：机制如何运作 → 可还原到物理化学
- 终极（ultimate）：为何被选择保留 → **功能/系谱解释，不可还原**
（Mayr 的 near/ultimate 之分；`report_D` 亦记「生物功能非物理化学问题」）

⇒ 生物学**不是**"化学的应用"，而是一个**有自己解释类型的基础领域**。
⇒ 但它**可以内部再分**：分子/细胞/生理/行为/生态/演化 —— 这些是**子域**，
   按 J1/J2 逐层检验，某些（如分子生物学）可能降级为化学的子问题簇。

### 3.3 **对机器而言的真正后果（这才是要紧的）**
生物学母题的**判定路由几乎都不是数值/仿真**，而是**系谱证据 + 功能恰当性**。
⇒ **机器建不了这类判定器。** 这不是理论问题，是工程现实：
当前管线里数学引擎 8 个，生物相关 0 个（`tri_verifiers` 里的"生物选择"也是硬编码的仿真玩具）。

## 四、范围划定的**真正取舍**（R22–R33 实测得出，与纸面直觉相反）

把两件事放在一起看：

| 领域 | 判定路由可得性（机器可建判定器吗） | 领地稀疏度（还有没被问过的吗） |
|---|---|---|
| **数学** | ✅ **最好**（数值/构造/形式证明都能自动化） | ❌ **最拥挤**（R25：加性数论 11 问**全部已发表**） |
| **生物 / 心理 / 工程 / 伦理** | ❌ 差（需系谱证据/实验/行验，机器建不了） | ✅ **稀疏**（少人做，因为难判） |

**这是本项目最关键的范围结论**：

> **"哪些领域基础"与"机器该做哪些领域"是两个不同的问题。**
> 按基础性（J1–J6），生物和心理都是基础领域，与数学平起平坐。
> 但按**机器可行性**（判定路由 × 领地稀疏度），存在一个**结构性错配**：
> **判定路由好的领域已被问烂；领地稀疏的领域机器判不了。**

⇒ 因此范围的划定**不该只按"哪个更基础"**，而应按二维 **判定路由可得性 × 领地稀疏度**。
⇒ 现实的可操作带：**数学中"判定路由好但少人做"的角落**（这正是 R26–R30 找到的进制依赖领地：
回文数依赖进制 ⇒ 加性数论的成熟工具不直接适用 ⇒ 稀疏；同时它有数值判定路由 —— 机器能判）。
⇒ **真正要把范围推到生物/心理，前置条件是先给这些域造判定路由**（实验接口 / 系谱证据库），
   那是比"发现新问题"大得多的一项工程。

## 五、给下一步的具体建议

1. **本文即刻生效**：母题判据用 ①–⑥（不再只用 ①–③）；领域裁定沿用 J1–J6。
2. **范围决策**：短期继续待在「**判定路由好 × 领地稀疏**」带内（进制/迭代/组合的边角），
   这是唯一能同时满足"机器可判"与"还没被问过"的区域。
3. **若要跨域**：先造判定路由，再谈发现。顺序不能反 —— 先跨域会发现
   "提出了一堆判不了的问题"（= R23 的 73% 不可判，只是换了个域重演）。
4. **领域宪章五件套**逐域补齐时，**判定路由一栏必须实打实可跑**，不许写占位。
