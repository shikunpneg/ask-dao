  而机器的手段(周期/类库包含/小界/密度)**没有归约原语**, 到不了这一步 -> Axis F 要补的是**归约**, 不是更多扫描。
- **生成侧缺陷(待修)**: 机器把 base3 的 k=3/4/5 问了三次, 但若 max=3 成立则 k=4/5 被蕴含 -> 
  需识别"被更强形式蕴含的弱形式", 避免虚增计数。
- **Phase 1 DoD 达成**: 3 领地 + 自动化沉默代理。**N3 = 0, 世界新问题 = 0 不变**。
