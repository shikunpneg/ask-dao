## C1：偶数 = 无平方因子数 + 无平方因子数？→ 已判已知(Estermann 系)，无需人工

## C2：`R2_无三3` — 偶数 = 无平方因子数 + 三角数

- **机器命题**：6..40000 内**每个偶数**都可写成（无平方因子数）+（三角数 T_n=n(n+1)/2）。
- **机器证据**：双类两数和覆盖扫描，范围 6..40000，**零反例**；状态 `真(验证到上限)`。
- **查证器结论**：检索未见直接文献（邻近只有 Sun 的"平方数+三角数"混合和系 [Universal.pdf](http://maths.nju.edu.cn/~zwsun/Universal.pdf)；未见"无平方因子+三角"条目）。
- **请人工核验**：
  1. 是否存在 >40000 的偶数反例？（扩界计算/解析论证）
  2. 文献是否已有"每个大整数=平方free+多角数"类结果？（建议检索词：*squarefree number triangular number additive representation*）
  3. 若真，证明路线候选：筛法/圆法处理 `n − m(m+1)/2` 无平方因子（对 m 求和）；
  4. 与我们已知的 `无平方因子+无平方因子`（Estermann 系）是否可复合推出。

## C3：`R2_无半3` — 偶数 = 无平方因子数 + 半素数

- **机器命题**：6..40000 内每个偶数都可写成（无平方因子数）+（半素数）。
- **机器证据**：同法扫描零反例；`真(验证到上限)`。
- **查证器结论**：检索级未见；邻近=Chen 族（质数+半素数）与 [stackexchange 双半素数(相异因子)](https://math.stackexchange.com/posts/5121437/revisions)。
- **请人工核验**：同上 4 问（文献：*squarefree semiprime sum every large even*）。
