## C2：`R2_无三3` — 偶数 = 无平方因子数 + 三角数

- **机器命题**：6..40000 内**每个偶数**都可写成（无平方因子数）+（三角数 T_n=n(n+1)/2）。
- **机器证据**：双类两数和覆盖扫描，范围 6..40000，**零反例**；状态 `真(验证到上限)`。
- **查证器结论**：检索未见直接文献（邻近只有 Sun 的"平方数+三角数"混合和系 [Universal.pdf](http://maths.nju.edu.cn/~zwsun/Universal.pdf)；未见"无平方因子+三角"条目）。
- **请人工核验**：
  1. 是否存在 >40000 的偶数反例？（扩界计算/解析论证）
  2. 文献是否已有"每个大整数=平方free+多角数"类结果？（建议检索词：*squarefree number triangular number additive representation*）
  3. 若真，证明路线候选：筛法/圆法处理 `n − m(m+1)/2` 无平方因子（对 m 求和）；
  4. 与我们已知的 `无平方因子+无平方因子`（Estermann 系）是否可复合推出。

## LLM 初步数学判断（2026 起，供人工参考，非盖章）

### 证据加强（本轮执行）
两个候选的扫描范围从 40000 扩到 **300000**：各检查 130,000 个偶数（40002..300000 步长2），**反例 = 空**（`tools/extended_probe.py` 可复跑）。

### C2（偶数 = 无平方因子数 + 三角数）— LLM 判断：**大概率真**
- **密度启发**：对偶数 n，三角数 T_m≈m²/2 有 ~√(2n) 个候选；每个 r=n−T_m 是无平方因子数的概率 ≈ 6/π²≈0.61（相互近似独立）→ 若无结构障碍，所有大偶数都应有表示；奇偶上无阻塞（平方free 可奇可偶）。与 30 万零反例一致。
- **可证路线**：`n−T_m` 在二次序列上取无平方因子值 —— 属 Hooley 式"多项式取平方free值"的经典圆法/筛法领地；给出正下界（不只渐近）即可证"所有足够大的偶数"。
- **新颖性**：弱。这类"稠密集相加覆盖全偶数"的命题在加法数论里更可能作为标准方法的推论/引理存在，未必被单独记录；**更像可证引理而非新猜想**。

### C3（偶数 = 无平方因子数 + 半素数）— LLM 判断：**大概率真，同上**
- 半素数密度 ~(log log n)/log n（在 3×10⁵ 处 ≈0.2），每个 n 有 ~0.2·√(2n) 个候选 → 大概率有表示；30 万零反例一致。
- 可证路线：`n−T_m` 为半素数的多项式值问题 —— Chen 型筛法领地，应可证"所有足够大的偶数"。
- 新颖性：弱，同样倾向"标准筛法推论"。

### 机器给人工的行动建议（按优先级）
1. 先查 OEIS 与 zbMATH 的关键词（squarefree & triangular / squarefree & semiprime 的加法表示）——**最可能结局：已在文献或等价可推**；
2. 若查无，则把它当作**可证明的小引理**（尝试给出 300k 之外的下界证明），投稿价值中等；
3. **不建议把这两条当作"世界新问题"来宣传**——按口径它们连"惊喜候选"的硬标准都偏弱，属于"生成器正确性+查证纪律"的演示品。
